Cloud infrastructure / Biomedical imaging

Neuron Segmentation
Platform

Bringing automated cell segmentation into a web-based research workflow.

The problem

Researchers need a way to submit microscopy images, run segmentation models, and retrieve analysis outputs through a consistent workflow.

My contribution

I built and deployed the AWS infrastructure and integrated existing SWIN (PyTorch) and ANMAF (TensorFlow) models for automated inference. I configured storage, authentication, job management, and model execution.

What it supports

Image uploads, queued segmentation jobs, user-visible processing status, and retrieval of completed analysis outputs.

  • API Gateway
  • Lambda
  • Cognito
  • DynamoDB

Scientific software / Data analysis

LabStats

From experimental spreadsheets to reproducible analysis.

The problem

GraphPad Prism’s licensing costs motivated us to develop a free alternative in R. Our goal was to let researchers inspect and share the code behind their analyses and graphs, making the methods more transparent, easier to review, and reproducible.

My contribution

I developed a locally hosted R Shiny application with CSV/Excel import, interactive visualization, multiple comparisons, and reproducible analysis exports.

What it supports

T-tests, ANOVA, mixed-effects modeling, and nested analyses, with R-script and publication-quality figure exports.

  • R
  • Shiny
  • Statistical modeling
  • Data visualization

Research by Tahsan Ul Alam, Sam Akerman-Knopf, and Victoria Do.

Machine learning / Agricultural research

Agricultural Image
Classification

Exploring crop classification when training data is limited.

The problem

Distinguishing crop types from images with small datasets introduces challenges in model performance, data quality, and generalization.

My contribution

I co-developed binary and multiclass CNN classifiers using pretrained VGG16 and Xception models. Our work explored augmentation, fine-tuning, mislabeled data, and DCGAN-based synthetic image generation.

74.19%

Best reported multiclass test accuracy
with Xception, augmentation, and fine-tuning.
